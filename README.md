## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Flight Tuning** | Adjust lift, speed and rotation sensitivity for each flyable vehicle |
| **Altitude Cap** | Set maximum flight height per vehicle or globally |
| **Control Profiles** | Save separate input sensitivity configs for gamepad and keyboard |
| **Feature Toggles** | Enable or disable specific flight features per session |
